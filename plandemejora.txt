✏️ Cambios en assets/css/design-system.css
1. Eliminar la restricción max-width del título principal
Busca la regla .hero h1 (está dentro de un bloque de selectores múltiples, hacia la mitad del CSS). Actualmente tiene:

css
.hero h1,
.section-heading h2,
.hero-spotlight h2,
.story-panel h3,
.contact-copy h2 {
    margin: 0;
    font-family: var(--font-display);
    line-height: 0.94;
    letter-spacing: -0.03em;
}

.hero h1 {
    font-size: clamp(3.4rem, 7vw, 6.6rem);
    max-width: 11ch;
}
Reemplaza la línea max-width: 11ch; para eliminarla (o coméntala):

css
.hero h1 {
    font-size: clamp(3.4rem, 7vw, 6.6rem);
    /* max-width: 11ch;  ← ELIMINADO para que el título se muestre completo */
}
2. Ajustar la animación typewriter
Localiza el bloque de la clase .typewriter (justo antes de las reglas de la preloader):

css
.typewriter {
    overflow: hidden;
    white-space: nowrap;
    border-right: 2px solid var(--accent);
    animation: typing 3s steps(40) 1s forwards, blink 0.75s step-end infinite;
}
Modifícalo para que tenga el número correcto de pasos (el título tiene 63 caracteres incluyendo espacios) y una duración ligeramente mayor para que el efecto sea fluido:

css
.typewriter {
    overflow: hidden;
    white-space: nowrap;
    border-right: 2px solid var(--accent);
    animation: typing 4s steps(63) 1s forwards, blink 0.75s step-end infinite;
}
3. Añadir una media query para desactivar el effecto typewriter en móviles
Al final del archivo, justo antes de la media query (prefers-reduced-motion: reduce), añade este bloque:

css
/* ── Desactiva el efecto typewriter en pantallas pequeñas ── */
@media (max-width: 860px) {
    .typewriter {
        white-space: normal;   /* Permite saltos de línea */
        overflow: visible;     /* Muestra todo el contenido */
        border-right: none;    /* Quita el cursor parpadeante */
        animation: none;       /* Elimina la animación */
        width: auto;
    }
}
4. (Opcional) Mejorar la legibilidad en pantallas muy pequeñas
Dentro de la media query (max-width: 680px) que ya existe, puedes agregar un ajuste de tamaño de fuente para el título. Busca ese bloque (aproximadamente línea 760 del archivo) e incluye:

css
@media (max-width: 680px) {
    /* ... otros estilos ... */

    .hero h1 {
        font-size: clamp(2.4rem, 8vw, 4rem);
        max-width: none;
    }
}
Si no quieres tocar ese bloque, puedes crear una regla independiente justo después del bloque de 860px:

css
@media (max-width: 680px) {
    .hero h1 {
        font-size: clamp(2.4rem, 8vw, 4rem);
    }
}
🧪 Comprobación tras los cambios
En escritorio (>860 px):
El título se escribirá letra a letra con el efecto máquina de escribir, ocupando una sola línea gracias al white-space: nowrap, pero sin estar cortado por el max-width: 11ch.

En tablet / móvil (<860 px):
El efecto typewriter desaparece automáticamente; el título se muestra entero, puede ocupar varias líneas y el texto se ajusta al ancho de la pantalla.

Tamaño de fuente:
Con la regla opcional, en móviles el título no será excesivamente grande ni se desbordará.

La clase typewriter ya está aplicada al <h1> correctamente:

html

Los cambios del CSS se encargarán de que funcione bien en todos los dispositivos.
